# 💰 Bank Loan Analysis

A data analytics project focused on analyzing loan application and borrower data to uncover lending trends, identify risk patterns, and support data-driven financial decision-making.

The project combines SQL, Python, Excel, and Power BI to transform raw financial data into actionable insights through interactive dashboards and analytical reporting.

---

## 🚀 Project Overview

Financial institutions process thousands of loan applications every day. Understanding borrower behavior, loan performance, and default risks is critical for making informed lending decisions.

This project analyzes loan data to identify key factors influencing loan approvals, repayment behavior, and potential default risks while providing meaningful business insights through visual dashboards.
